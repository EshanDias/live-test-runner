Features

Wallaby-style feedback for Jest and Vitest, built right into VS Code.

⚡

Reruns on save

Only the tests affected by the file you just saved run, so feedback comes in seconds, not minutes.

Every file, suite and test in the sidebar as soon as you open the project, before anything runs.

Editor feedback

Gutter icons, color-coded inline durations, and ▶ Run · ▷ Debug · ◈ Results above every test.

📊

Live code coverage

Per-line coverage bars in your source files. Hover a line to see exactly which tests hit it.

🔍

Results panel

Searchable test list, console output by level, and failure messages with stack traces side by side.

⏱

Timeline Debugger Preview

Step through a finished test line by line, with variable values shown inline. No breakpoints.

Coverage

See what your tests really touch

After the first run, every source file shows per-line coverage. No separate command, no report to open.

  • Green, amber and red bars: covered by all, some or no tests
  • Hover any line to list the covering tests with status and duration
  • Updates on every save as you work

Results

Output and errors, per test

A three-column panel puts the test list, its console output and its failures in one view.

  • Search and filter across files, suites and tests
  • Console output split by level (log, warn, error)
  • Vitest output is attributed to the exact test that printed it

Explorer

Your whole suite, always in view

The sidebar tree fills in on project open and turns green and red live as files finish. The status bar keeps a running count.

  • File → suite → test, including .each templates
  • Live per-file progress and a run timer
  • Rerun or debug any node with one click

FAQ

Questions

Which test frameworks are supported?

Jest (babel-jest, ts-jest, @swc/jest), Create React App (react-scripts 4 and 5) and Vitest 3+. Vitest 1 and 2 run with results only. The framework is detected from your project.

Do I need to change my Jest or Vitest config?

No. Live Test Runner uses your existing config and the test binary already in node_modules. Nothing extra is installed into your project.

Does it run tests in the background all the time?

No. Nothing runs until you click Start Testing, and Stop ends the session. Single ▶ Run and ▷ Debug clicks from the editor always work.

Is it free?

Yes. It is free and open source under the MIT license, on the VS Code Marketplace and on Open VSX for VSCodium, Cursor, Windsurf and other compatible editors.

How is it different from jest --watch?

Results show up where you write code: gutter icons per test, inline durations, Run and Debug buttons, per-line coverage with a hover listing the tests that hit each line, and a results panel with per-test output and errors.
